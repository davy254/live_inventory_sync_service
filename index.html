Simulates a POS sale or warehouse receiving event. Pushing a value here updates the sync feed instantly — reflected the moment support re-checks the item.

How this maps to production: this prototype simulates the sync feed in-browser so you can see the interaction pattern end to end. In production, "Push update" would be replaced by a webhook from your POS/warehouse system (e.g. Shopify, NetSuite, a WMS) hitting a small backend endpoint, which writes to a shared inventory store. The support tool's lookup would query that store directly (or via websocket for push updates) instead of the local array used here — so agents always see the same number the warehouse just saw, without page refresh or manual reconciliation.
